# Sistema de Mapeamento e Localização de Serviços

Aplicação web desenvolvida com React, Node.js e PostgreSQL, com o objetivo de visualizar, organizar e consultar pontos de serviço por meio de um mapa interativo. O projeto integra uma interface dinâmica a uma API REST, permitindo a comunicação entre o front-end e o banco de dados.

#Tecnologias utilizadas

#Front-end

JavaScript (ES6+) — lógica da aplicação.
React 19 — construção da interface.
React Router — gerenciamento de rotas e navegação.
Material UI (MUI) — componentes de interface.
Emotion e styled-components — estilização dos componentes.
Radix UI — componentes acessíveis e ícones.
Leaflet e React Leaflet — mapas interativos.
Axios — comunicação com a API.

#Back-end

Node.js — ambiente de execução JavaScript.
Express — criação e gerenciamento das rotas da API.
PostgreSQL — banco de dados relacional.
node-postgres (pg) — integração com o banco de dados.
CORS — configuração do acesso à API entre diferentes origens.

#Funcionalidades

Sistema de login e navegação entre páginas.
Visualização de pontos de serviço em um mapa interativo.
Exibição de localizações e informações dos serviços cadastrados.
Listagem de pontos de serviço.
Integração entre front-end, API REST e banco de dados.
Navegação entre as páginas utilizando React Router.
